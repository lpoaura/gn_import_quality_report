# Rapport Automatisé des Données importées 

Ce projet contient le code permettant de générer automatiquement des rapports récapitulatifs des données naturalistes pour les données importées dans un géonature.  
Les rapports incluent des graphiques temporels et spatiaux, ainsi que des tableaux de répartition taxonomique, et analyses de doublons. 

Les rapports ont pour objectif d'échanger avec les différentes structures, de leur données fournies afin d'identifier des incohérences ou améliorations. 

---

## Description

Le workflow permet de :

- Extraire et traiter les données  depuis votre base géonature
- Générer des rapports automatisés au format HTML.
- Visualiser :
    1. Informations générales
    2. Répartition temporelle
    3. Répartition spatiale
    4. Répartition par groupe taxonomique
    5. Répartition en fonction des métadonnées
    6. Validation des données
    7. Analyses des potentiels doublons
    8. Synthèse sur les Espèces Exotiques Envahissantes (EEE)
